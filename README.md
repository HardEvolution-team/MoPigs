# Mo' Pigs Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Mo' Pigs** by its original author.

- Original: https://www.9minecraft.net/?p=75909
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.25.0+

This port contains **no original assets**. Put your own copy of the original jar (`mo_pigs_1.0.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
